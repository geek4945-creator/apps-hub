About

JD's Apps lists every live app and APK from geek4945-creator, with the newest version of each.

The list is a file, apps.json. It is rebuilt every night at midnight (Pacific time) from the latest GitHub releases, so new versions appear without updating this app.

Android APKs install after you allow “Install unknown apps” for your browser. Source: apps-hub.
